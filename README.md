# Primeiro Projeto – Cálculo de Potência Mensal
Este projeto em Python foi criado para praticar o ciclo **Entrada → Processamento →
Saída**.
O programa solicita o **nome do aparelho**, sua **protência** e **quantas horas diárias são utilizadas** pelo mesmo, dadas as  informações, é calculada a potência mensal em Kw/h e por fim mostra-se o aparelho, sua potencia e seu gasto com a referencia de 0,90 reais por Kw.
